CMD and ENTRYPOINT both are used ti run the conatinaer 

CMD 
Defines the default command to run in a container and Can be overridden at runtime

CMD ["node", "App.js"]  (in dockerfile)
CLI docker run myapp node test.js  (myapp is name)
Runs: node test.js (CMD overridden)

ENTRYPOINT
Defines the fixed main command Cannot be overridden, only arguments can be added

ENTRYPOINT ["node"]  (fixed)
CMD ["App.js"]    (can be changes)
docker run myapp test.js
Runs: node test.js

CMD → flexible (can change completely)

ENTRYPOINT → fixed (only arguments change)
